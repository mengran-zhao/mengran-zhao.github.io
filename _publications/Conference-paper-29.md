In this paper, the super-resolution imaging using vortex waves carrying orthogonal orbital angular momentum (OAM) generated by a concentric circular array (CCA) is investigated. Firstly, a multi-mode OAM-based radar imaging architecture is implemented, and the mathematical model of the multi-mode OAM radar system based on array synthesis theory is derived. Then, the OAM imaging is treated as an inverse problem and can be solved by the optimization algorithm. The super-resolution capability of the multi-mode OAM-based imaging system is thoroughly evaluated using sparse Bayesian learning (SBL) for image reconstruction. Simulation results show that 5.5 times super-resolution can be achieved compared with the phased array radar with the same aperture size when the signal-to-noise ratio (SNR) is maintained at 20 dB.
